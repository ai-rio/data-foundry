## 📋 Organization Categories

### API Documentation
Contains all API-related documentation including endpoint specifications and security considerations.

### Architecture
System architecture documentation, data models, and high-level design documents.

### Compliance
GDPR and regulatory compliance documentation, including audit reports and implementation matrices.

### Development
Development processes, methodologies, and integration guides for developers.

### Guides
User guides, quick references, and integration tutorials for various systems and components.

### Project Management
Phase tracking, project status, and planning documents for the Data Foundry project.

### Reports
Comprehensive QA audits, security assessments, and technical reports.

### Security
Security documentation including incident response procedures and security controls.

## 🔍 Quick Access

**For GDPR Compliance**: Start with `compliance/COMPLIANCE_DOCUMENTATION_INDEX.md`

**For Development**: See `development/DEVELOPER_INTEGRATION_GUIDE.md`

**For API Documentation**: Check `api/` directory

**For Security Information**: See `security/SECURITY_CONTROLS.md`

**For Project Status**: Review `project-management/PROJECT_STATUS.md`
